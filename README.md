VS Code


What is VS Code?
VS Code (Visual Studio Code) is a lightweight and powerful code editor developed by Microsoft. It supports Java and many other programming languages through extensions.


Download
Download VS Code: https://code.visualstudio.com/download
Installation steps
Download the installer for Windows.
Open the installer.
Click Next until the installation options appear.
Check:
Add to PATH
Add "Open with Code"
Click Install.
Recommended extensions
Material Icon Theme
Extension Pack for Java
Prettier
Error Lens
GitLens
Java JDK
What is JDK?

JDK (Java Development Kit) contains the Java compiler and runtime required to develop and run Java programs.

Download
Download JDK: https://www.oracle.com/java/technologies/downloads/
Installation steps
Download the latest LTS version.
Install it with the default settings.
Copy the installation path.

Example:

C:\Program Files\Java\jdk-24
Configure environment variables

Create a system variable:

JAVA_HOME=C:\Program Files\Java\jdk-24

Add this to the Path variable:

%JAVA_HOME%\bin
Verify installation

Open Command Prompt and run:

java -version
javac -version
